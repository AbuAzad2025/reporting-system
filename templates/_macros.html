{# ============================================================ Shared UI components. The templates were written before any component layer existed, so the same field, card and button were re-spelled in 30 files. That is how 41 inputs ended up styled with a hand-written class string while 26 used the design system's own .form-control: two spellings of one control, and inputs that look different from each other on the same page. These macros are the single spelling. They also fix what the copies had in common: a label with no `for`, so clicking it did nothing and a screen reader could not tie the two together.
